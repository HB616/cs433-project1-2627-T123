\begin{abstract}
We developed a NumPy-only linear soft-margin SVM for predicting myocardial
infarction or coronary heart disease from the imbalanced BRFSS survey data.
Codebook-aware missing-value handling and categorical encoding were combined
with positive-class-weighted hinge loss. On a complete-data stratified holdout,
threshold zero achieved 0.7710 balanced accuracy, 0.7284 recall, and 0.3989 F1.
Selecting threshold 0.5009 by validation F1 yielded local F1 0.432 and accuracy
0.868; the hidden-test AIcrowd result (F1 0.431, accuracy 0.866) closely matched
these values, providing a reproducible SVM contribution for the group report.
\end{abstract}

\section*{Reproducibility}

The report statistics and figures are regenerated from the raw course dataset
with:
\begin{verbatim}
python3 generate_svm_report_assets.py \
  --data-dir ../../dataset --max-rows 0 \
  --output-dir report/svm/assets
\end{verbatim}
The final AIcrowd prediction file is generated with:
\begin{verbatim}
python3 run.py --data-dir ../../dataset \
  --output outputs/submission-svm-brfss.csv
\end{verbatim}
